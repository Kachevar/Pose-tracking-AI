# 🕺 Pose-tracking-AI

**Pose-tracking-AI** is a Python-based project for real-time human pose detection using the **YOLOv8 Pose Estimation model**.

The system detects and visualizes human body keypoints from a live webcam or video stream and can be used as a base for pose tracking, motion analysis, fitness, and gesture recognition applications.

---

## 🚀 Features

- Real-time pose detection
- YOLOv8 pose model (`yolov8s-pose.pt`)
- Webcam / video stream support
- Simple Python implementation
- Windows quick start via `.bat` file
